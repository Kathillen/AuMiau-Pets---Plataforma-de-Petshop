# Aumiau — Catálogo de Serviços para Pet Shop

> **Status: Em desenvolvimento**

Sistema desenvolvido em **Python** para fins acadêmicos, com o objetivo de apresentar um catálogo de serviços oferecidos pelo **Pet Shop Aumiau**.

O sistema permite consultar os serviços disponíveis e calcular o valor de acordo com o **peso do animal**, aplicando diferentes faixas de preço conforme o porte do pet.

## Sobre o projeto

O **Aumiau** foi desenvolvido como um projeto acadêmico para praticar conceitos de programação em Python, estruturas condicionais, funções, entrada e saída de dados e organização de código.

A proposta é simular um sistema de atendimento de um pet shop, no qual o cliente informa o peso do animal e escolhe um serviço disponível.

O preço do serviço será calculado automaticamente com base no peso do animal.

### Classificação por peso

| Porte   |                     Peso |
| ------- | -----------------------: |
| Pequeno |                Até 10 kg |
| Médio   | Acima de 10 kg até 25 kg |
| Grande  | Acima de 25 kg até 40 kg |
| Gigante |           Acima de 40 kg |

> Os valores e faixas utilizados no projeto são definidos para fins acadêmicos e podem ser alterados conforme a necessidade do sistema.

# Aumiau — Pet Shop Service Catalog

> **Status: In Development**

A **Python** project developed for academic purposes to create a service catalog for **Aumiau Pet Shop**.

The system allows users to view the available services and calculate prices according to the **animal's weight**, applying different price ranges based on the pet's size.

## Project Status

## About the project

**Aumiau** was developed as an academic project to practice Python programming concepts, conditional statements, functions, user input and output, and code organization.

The project simulates a pet shop service system where the customer enters the animal's weight and selects an available service.

The service price will be automatically calculated based on the animal's weight.

### Weight classification

| Size   |                 Weight |
| ------ | ---------------------: |
| Small  |            Up to 10 kg |
| Medium | Over 10 kg up to 25 kg |
| Large  | Over 25 kg up to 40 kg |
| Giant  |             Over 40 kg |

> The values and weight ranges used in this project are defined for academic purposes and can be modified according to the system requirements.

## Services

The catalog includes services such as:

* Bath
* Grooming
* Hydration
* Pet transportation

Each service has a base price that may vary according to the animal's weight.

### Example prices

| Size   |     Price |
| ------ | --------: |
| Small  |  R$ 40.00 |
| Medium |  R$ 60.00 |
| Large  | R$ 100.00 |
| Giant  | R$ 130.00 |

The prices above are examples used to demonstrate the system logic.
